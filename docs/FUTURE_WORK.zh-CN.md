# 未来工作

本文列出 ScaleNative 首次公开发布（`v0.2.0`）之后要做的工作，分两层。

- **近期**（第 1 节）：作者已经定下、但还没有做进 RTL，或者已在 RTL 里但还没有验证的事项，
  逐项推进。它们合起来就是本仓库的 RTL 与论文所述目标设计之间的差距。
- **远期**（第 2 节）：项目现阶段不会实现，但将来流片或完整论证硬件可行性时需要做的方向。
  只列方向，不给结构与数字。

论文的 Future Work 一节只写远期一层；本文两层都写。

本文是英文版 [FUTURE_WORK.md](FUTURE_WORK.md) 的中文对照；两版不一致时以英文版为准。

## 读法

- 每一条都写「现在的状态」与「下一步」。不承诺日期。
- 第 1 节里的数字，要么是作者选定的设计目标，要么是今天 RTL 的属性，都不是测得的性能结果。
- 「规划点」指作者在实现与实测之前先按它来规划的取值，有了实测之后可能调整。
- 「不在 RTL」指本仓库的 RTL 没有实现该项。
- 已发布的 RTL 与版图存在的问题，列在 [README](../README.zh-CN.md) 的「已知限制」一节。
  本文只写打算怎么做，不重复那张清单。
- 名称与 README 一致：Tensor 单元；Vector 单元（今天）与 Vector 核（目标设计）；交接
  （Tensor 单元到 Vector 一侧的直连通路，传的是「16 个尾数加一个共享指数」的块）；
  本地存储（L2）；控制核（PE 内的 Ibex 核）；命令处理器；DMA 引擎。tile 指 16 x 16
  Tensor 阵列的一个工作单位。
- 本仓库是一个中间快照。下面的 RTL 改动合入之后、全量测试在其上通过之后，会有后续发布。
